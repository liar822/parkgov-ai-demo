# ParkGov AI 线上部署检查清单

本项目的公开演示链路固定为：Netlify 前端 + Render 后端 + Neon PostgreSQL。

## 基本原则

- 前端不能使用静态假数据冒充实时余位。
- 后端不可用时，用户端显示“后端服务未连接”，不展示伪造停车场余位。
- 线上演示仍然是校园试点、公开数据样例和 AI 数据集验证，不声明已接入全北京真实摄像头。

## Neon PostgreSQL

1. 创建 Neon 项目和数据库。
2. 复制连接串到 Render 的 `DATABASE_URL`。
3. 确认连接串带 SSL，或在 Render 设置 `DATABASE_SSL=true`。

本地发布前先设置：

```bash
export DATABASE_URL="postgresql://...sslmode=require"
```

## Render 后端

项目根目录已有 `render.yaml`，可作为 Render Blueprint 使用。

必须设置：

```bash
DATABASE_URL=postgresql://...
DATABASE_SSL=true
FRONTEND_URLS=https://你的-netlify-站点.netlify.app
JWT_SECRET=一个足够长的随机字符串
PYTHON_PATH=python3
AI_SERVICES_PYTHON=python3
```

本地发布前先设置：

```bash
export RENDER_API_KEY="..."
```

部署后先检查：

```bash
curl https://你的-render-backend.onrender.com/api/health
```

数据库初始化与演示数据：

```bash
cd backend
npm run check:db-init
npm run seed:mvp
npm run demo:ai-run
npm run backfill:ai-jobs
npm run check:api
```

说明：`demo:ai-run` 使用已登记的公开数据集 JSON 回放，适合 Render 免费服务快速生成线上演示数据。`demo:ai-infer` 会调用 Python 模型和样例图/视频，建议先保留在本地或后续单独配置模型文件与 Python 依赖后再在云端运行。

## Netlify 前端

前端目录已有 `frontend/netlify.toml`。

Netlify 必须设置：

```bash
VITE_API_URL=https://你的-render-backend.onrender.com/api
VITE_WS_URL=https://你的-render-backend.onrender.com
VITE_ENABLE_REAL_MAP=true
VITE_MAP_STYLE_URL=https://tiles.openfreemap.org/styles/positron
```

本地发布前先设置：

```bash
export NETLIFY_AUTH_TOKEN="..."
export VITE_API_URL="https://你的-render-backend.onrender.com/api"
export VITE_WS_URL="https://你的-render-backend.onrender.com"
```

构建配置：

```bash
Base directory: frontend
Build command: npm run build
Publish directory: frontend/dist
```

## 验收路径

- `GET /api/health` 返回正常。
- `/parking-lots` 能读取 Render 后端停车场数据。
- 后端关闭或环境变量错误时，用户端显示服务不可用状态。
- 管理员演示账号能进入 `/admin/video`。
- `/admin/video` 能看到 CNRPark+EXT 训练结果和 AI 写回证据。
- 页面不出现“已接入全北京摄像头”“真实部署”“政府合作”等表述。

## 本地脚本

部署包已内置脚本，避免手动敲错命令：

```bash
scripts/deploy/check-prereqs.sh
scripts/deploy/push-github.sh parkgov-ai-demo
scripts/deploy/seed-online-db.sh
scripts/deploy/deploy-netlify.sh
```

GitHub 发布前还需要：

```bash
export GITHUB_TOKEN="..."
```

说明：`check-prereqs.sh` 会检查 `gh`、`netlify`、`render`、`node`、`npm` 和四个必需环境变量。任何缺失都不会继续发布，避免生成不能演示的假链接。
